Thermal Lab 1.0.0 — 가열과 냉각 실험대

설치 후 바탕화면 또는 시작 메뉴의 Thermal Lab 아이콘으로 시작합니다.
인터넷 없이 실행하며 Node.js나 개발 서버가 필요하지 않습니다.
두 물체의 평균 온도를 다루는 교육용 실험 앱입니다.
실제 검사·설치·업데이트 결과는 해당 릴리스 기록을 따릅니다.

25 °C에서 히터와 방열 모듈의 평균 온도 변화를 관찰합니다.
전력은 0/4/8/12 W, 시간 배속은 1/10/60입니다.
전력과 팬 변경은 현재 온도를 유지하며 변경 시각을 기록합니다.
모듈·접촉 교체는 새 조건으로 25 °C에서 다시 시작합니다.
일시정지는 시간을 멈추는 동작이며 0 W로 전원을 끄는 것과 다릅니다.
+60초/+300초는 실제 모형 시간 진행이며 예상 정상온도를 붙여 넣지 않습니다.
전원을 끈 뒤 방열판이 잠시 더 따뜻해져도 전체 저장 에너지는 줄 수 있습니다.

온도는 °C, 화면 변화율은 °C/분, 순간 열 흐름은 W, 누적 에너지는 J입니다.
일시정지 중 변화율은 모형 시간을 다시 진행할 때의 기울기입니다.
보관한 실험과 현재 이력이 겹치면 마지막 시간·온도 수치를 함께 확인하세요.
색상은 두 물체의 평균 온도이며 실제 열화상·핀 내부 분포가 아닙니다.
팬과 화살표는 설명용이며 실제 RPM·유속을 표시하지 않습니다.
열용량·접촉·방열 계수는 교육용 예시값이며 실제 제품 성능이나 안전 기준이 아닙니다.

파일: Ctrl+N 새 실험, Ctrl+O 열기, Ctrl+S 저장.
재생/일시정지: Ctrl+Shift+P. 3D 크게 보기: Ctrl+Shift+F. 도움말: F1.
프로젝트에는 초기 조건·시간·변경 이력·비교 실험·관찰 시점을 저장합니다.
불러오기와 재시작은 일시정지 상태이며 안내 진행은 세션 안에서만 유지합니다.
손상·미래 버전 원문은 내보내기로 따로 보관하고 덮어쓰지 마세요.
도움말의 저장 폴더 열기로 로컬 프로필에 접근합니다.

코드 서명과 자동 업데이트를 제공하지 않습니다.
실험을 저장하고 앱을 닫은 뒤 새 설치 파일로 수동 업데이트합니다.
제거 설정은 사용자 앱 데이터를 자동 삭제하지 않도록 구성했습니다.
실제 제거 실행 검사는 설정 확인과 구분합니다.
