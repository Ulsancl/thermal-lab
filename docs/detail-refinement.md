# Thermal Lab 상세 관찰의 계산 범위

기존 `thermal-two-node-1`의 두 평균온도 계산을 부품별 관찰과 연결한다. 계수, 정확한 구간 진화, 실험 사건, 표본과 저장 형식은 그대로다. 공개 배포와 화면·설치 검증 결과는 해당 릴리스 기록을 따른다.

## 현재 열 흐름과 정상상태

히터 평균온도를 Th, 모듈 평균온도를 Ts, 주변온도를 Ta로 둔다. 현재 접촉 온도차는 `Th−Ts`이고 접촉 열률은 `Qc=(Th−Ts)/Rc`다. 공기 쪽은 `Qa=Ga(Ts−Ta)`다. 양의 Qc는 히터→모듈, 양의 Qa는 모듈→공기 방향이다. 부호를 잘라서 냉각·역방향 전달을 가열처럼 만들지 않는다.

공기 열저항은 `Ra=1/Ga`, 전체 직렬 경로의 열저항은 `Rc+Ra`다. Rc·Ra의 단위는 K/W, 역수인 열전달도의 단위는 W/K다. W/(m·K)의 재료 열전도율이나 W/(m²·K)의 면적당 대류 계수와 다르다. 화면의 패드 두께·핀 표면적·나사 조임 힘으로 이 교육용 계수를 역산하지 않는다.

현재 전력 P와 팬 상태를 유지한 정상 참조는 다음과 같다.

```text
Ts∞ − Ta = P Ra
Th∞ − Ts∞ = P Rc
Th∞ − Ta = P (Rc + Ra)
```

과도 상태의 접촉 온도차에 `P Rc`를 대신 표시하지 않는다. 예를 들어 기본 12 W 실험의 시작 순간 현재 온도차는 0 K지만 정상 접촉 온도차는 6 K다. 그 순간 입력 12 W는 모두 히터에 저장되며 접촉·공기 전달은 각각 0 W다. 정상상태에서는 두 경로 모두 12 W가 전달되고 두 저장 변화율은 0 W다.

## 각 노드의 에너지와 열수지

저장열의 기준은 주변 25 °C다. 히터와 모듈의 개별 저장량을 보여 주므로 큰 열용량과 높은 온도가 서로 다른 개념임을 비교할 수 있다.

```text
Eh = Ch (Th − Ta)         dEh/dt = Ch dTh/dt = P − Qc
Es = Cs (Ts − Ta)         dEs/dt = Cs dTs/dt = Qc − Qa
E저장 = Eh + Es           dE저장/dt = P − Qa
```

Eh·Es는 J, 저장 변화율과 열률은 W다. Qc는 내부 전달이므로 전체 수지에 다시 더하지 않는다. 전원을 0 W로 바꿔도 뜨거운 히터가 모듈을 덥힐 수 있다. 이때 히터 저장 변화율은 음수, 모듈 저장 변화율은 양수일 수 있으며 전체 저장열은 공기로 전달된 만큼 줄어든다.

누적 입력열은 원래 실험이 적분한 전력 이력이다. 누적 공기 전달열은 기존 `입력열−저장열` 회계값을 그대로 읽는다. 상세 계측의 수지 잔차가 작다는 것만으로 독립 실험 검증이 되지는 않는다. 별도 수치 검증에서 두 온도 미분방정식과 공기 열률을 독립 RK4로 적분해 각 노드의 에너지와 비교한다. 극히 짧은 시간에 생기는 작은 부동소수점 잔차나 음의 0 근처 값을 물리적 손실로 새로 만들거나 임의로 0에 맞추지 않는다.

일반 앱 실험은 주변온도에서 시작하고 전력은 음수가 아니다. 순수 계산에서 주변보다 차가운 유효 상태를 관찰한다면 주변 기준 저장열과 공기로 향하는 열률은 음수가 될 수 있다. 이를 절대 내부에너지의 음수로 해석하지 않는다.

## 두 감쇠 모드의 시간척도

현재 설정을 유지할 때 정상온도에서 벗어난 두 온도는 두 지수 성분의 합으로 변한다. 원래 상태방정식의 `a=1/(Rc Ch)`, `b=1/(Rc Cs)`, `c=Ga/Cs`에 대해 양의 감쇠율은 다음 특성방정식의 두 근이다.

```text
r² − (a+b+c)r + ac = 0
τ빠름 = 1/r빠름, τ느림 = 1/r느림

Th(t+Δt) − Th∞ = Ah,빠름 exp(−Δt/τ빠름) + Ah,느림 exp(−Δt/τ느림)
Ts(t+Δt) − Ts∞ = As,빠름 exp(−Δt/τ빠름) + As,느림 exp(−Δt/τ느림)
```

진폭 A는 **현재 상태−현재 설정의 정상상태**를 분해한 값이며 단위는 K다. 빠른 모드가 히터에만, 느린 모드가 모듈에만 속하는 것은 아니다. 각 노드에 두 성분이 있고 진폭은 서로 반대 부호일 수도 있다. 가열 시작 때 모듈의 두 성분은 초기 기울기가 0이 되도록 서로 상쇄한다.

| 조건 | 빠른 시간척도 | 느린 시간척도 |
| --- | ---: | ---: |
| 평판·좋은 접촉 | 7.453 s | 402.547 s |
| 핀·좋은 접촉·팬 꺼짐 | 8.527 s | 281.473 s |
| 핀·좋은 접촉·팬 켜짐 | 8.479 s | 141.521 s |
| 핀·나쁜 접촉·팬 켜짐 | 32.554 s | 147.446 s |

시간척도 하나가 지나면 해당 **성분**이 1/e, 약 36.8%로 줄어든다. 전체 온도의 같은 비율 감소, 정상상태 도달, 남은 시험 시간, 실제 제품 냉각 완료를 뜻하지 않는다. 전력과 경과 시간은 이 선형 모형의 감쇠율을 바꾸지 않지만 정상값과 진폭을 바꾼다. 팬 조작은 계수를 바꾸므로 시간척도도 바뀐다. 한 번의 시간척도 표시는 그 뒤 설정을 계속 유지한다는 조건부 참조이며 미래 사건을 예측하지 않는다.

## 부품 관찰과 생략한 물리

16개 부품마다 최대 6개 수치와 해석 범위를 표시한다. 히터·모듈·두 프로브는 같은 두 평균온도를 읽는다. 패드는 접촉 열저항이고 별도의 온도·열용량이 없다. 단열 받침·실험대·배선·손잡이·나사·팬 프레임·보호망에 새로운 열 노드를 만들지 않는다.

팬은 핀 모듈의 유효 공기 열전달도를 바꿀 뿐이다. 그림에서 팬 RPM·풍속·유량·전력·압력 손실을 추정하지 않는다. 전원 표시의 P도 히터에 전달된 열전력이며 전압·전류·배선 손실·벽면 전력·팬 소비전력이 아니다. 핀 내부의 국소 온도 구배, 프로브 지연·측정 오차, 복사·접촉 안전성·온도별 재료 변화는 여전히 계산하지 않는다.

일시정지와 7200초 기록 한도는 모형 시간 진행을 멈춘다. 상세 변화율은 그 순간 설정으로 시간을 진행할 경우의 물리 기울기다. 멈췄다는 이유로 기울기를 0으로 바꾸지 않고, 표시를 위해 실험을 더 진행하지도 않는다. 0 W로 조작하는 것과 일시정지는 별개다.

## API와 원본 보존

`src/detail-model.js`는 다음 순수 API를 내보낸다.

- `thermalDetail(snapshot)`: `ThermalRun.getSnapshot()`의 적용된 설정·매개변수·온도·열률·에너지를 읽어 독립 객체를 반환한다. 잘못된 형식이나 설정과 불일치한 계수·정상 참조를 조용히 보정하지 않는다.
- `describeThermalDetail(partId, snapshot, detail?)`: `{facts:[{label,value,unit,digits}],note}`를 반환한다. 선택적으로 같은 snapshot에서 구한 detail을 재사용할 수 있다. 숫자는 단위에 맞는 값이며 문자열은 계산하지 않는 상태 설명에 사용한다.

`nodes.heater/sink`에는 현재·정상온도, `steady−current`의 온도차, 주변 대비 상승, 열용량, 변화율, 저장량과 저장 변화율이 있다. `path`는 두 열저항·열전달도·현재와 정상 온도차, `power`는 열률과 각 노드·전체 수지, `energy`는 저장·입력·공기 전달 누계와 잔차, `modes`는 두 감쇠율·시간척도·현재 편차 진폭이다. 모든 파생 물리량은 SI 단위이며 섭씨는 온도에, K는 온도차와 변화율에 사용한다.

실험·사건·곡선·비교·프로젝트를 수정하거나 새 필드를 저장하지 않는다. 초기 설정과 사건 적용 후 현재 설정을 혼용하지 않으며 표시 배속을 물리 변화율에 곱하지 않는다. 정상 참조나 모드 분석을 얻기 위해 `advance`나 가상의 조작을 호출하지 않는다.

## 검증

14개 상세 수치 검사는 24개 허용 설정, 독립 RK4의 개별 저장열·공기 전달 적분, 중앙 유한차분, 기본 행렬의 별도 닫힌식 감쇠율, 순수 모드의 1/e 응답, 고정 조건의 미래 온도 재구성, 전원 차단 후 모듈 가열, 역방향 전달과 주변 이하 상태, 사건 이후 현재 계수, 기록 한도, 16개 부품의 유한 수치·한계 설명, 원본 불변성 및 잘못된 입력 거부를 확인한다. 화면·기하·파일·Windows 앱 검증은 별도의 통합 검사다.
