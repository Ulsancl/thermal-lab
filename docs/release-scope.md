# 완성 기준과 한계

이 문서는 Thermal Lab 1.1의 유한한 기능 범위와 확인 기준입니다. 각 버전의 실제 계산·화면·설치·업데이트 결과는 해당 릴리스 기록을 따릅니다. 앱 검사는 외부 사용자 연구·실제 판매·유료 지원 검증을 뜻하지 않습니다.

- 두 평균 온도의 선형 열회로, 정해진 전력·모듈·팬·접촉 예시값을 다룹니다. 수치·온도색·그래프·열 흐름은 같은 상태를 나타내야 합니다.
- 전력·팬 변경은 온도 연속성을 유지하고 모듈·접촉 교체는 새 실험을 명시합니다. 일시정지와 0 W, 모형 시간과 벽시계 시간, 실제 과도응답과 예상 정상값을 구별합니다.
- 일시정지 상태의 변화율은 모형 시간 기준 기울기로 설명합니다. 같은 이력이 겹쳐도 보관한 비교의 마지막 시간·온도를 확인할 수 있어야 하며 두 곡선의 축을 따로 늘려 차이를 과장하지 않습니다.
- 세 안내 실험은 실제 시간·온도·에너지 관찰과 확인에 연결되어야 합니다. 저장·되돌리기·비교와 원문 보호가 일관되어야 합니다.
- 두 노드의 저장열·순간 열수지·열저항·감쇠 모드가 원래 상태와 일치해야 합니다. 시간상수와 정상 도달 시간을 혼동하지 않으며 부품별 계측은 새 물리 노드를 만들지 않습니다.
- 임시 내부 관찰은 실제 구멍·단면·체결 관계를 보여 주고 종료·파일 저장·복원 시 원래 관찰 시점을 보존해야 합니다.
- 구조의 접촉면·카트리지·두 프로브가 읽히고 부품 선택과 가까이 보기가 일치해야 합니다. 온도 표시가 두 평균값인데 공간 분포나 열화상처럼 보이게 만들지 않습니다.
- 순수 계산·이력·저장 검사, 브라우저 조작, 네이티브 메뉴·파일·재시작, 실제 설치·업데이트를 구분해 확인합니다. 런타임 오프라인 실행과 제품 정체성·고지·설치 파일 해시를 확인합니다.

하드웨어 범위는 기록된 Windows 11 x64, RTX 5080, 150% 배율과 실제 검사한 화면 크기에 한정합니다. 다른 GPU·모든 배율·원격 데스크톱·다른 운영체제까지 호환성을 확대하지 않습니다. 제거 설정의 정적 확인을 실제 제거 실행으로 주장하지 않습니다.

계수는 교육용 예시이며 실측 성능이 아닙니다. 실제 핀 온도 분포, 복사, 히터의 직접 공기 손실, 팬의 전력·유속·RPM·소음, 접촉면 압력 해석, CFD, 실물 온도 안전 한계와 최적 설계는 범위 밖입니다. 색상 범례 밖의 값도 수치와 혼동하지 않도록 읽어야 합니다.
