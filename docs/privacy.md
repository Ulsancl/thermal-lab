# 로컬 자료와 개인정보

설치 앱은 계산과 화면에 필요한 파일을 로컬에 포함합니다. 계정·광고·원격 분석·자동 오류 전송 기능은 구현하지 않습니다. 앱 화면의 HTTP/HTTPS 요청과 외부 창은 차단합니다. 개발 의존성 설치와 도구 준비는 별도이며 인터넷을 사용할 수 있습니다.

자동 저장, 창 위치와 실행 로그는 Thermal Lab 로컬 프로필에 남습니다. 사용자가 고른 실험 파일을 읽고 저장하며 원문 복구는 사용자의 선택으로 로컬 파일에 내보냅니다. 비교 이름과 실험 이력이 파일에 포함되므로 공유 전에 내용을 확인하세요.

문제 보고 자료에는 개인 파일 경로·환경 정보가 포함될 수 있습니다. 필요한 재현 단계만 남기고 민감한 정보와 불필요한 원문을 제거한 뒤 직접 공유하세요. 자동 저장은 외부 백업을 대신하지 않습니다.
