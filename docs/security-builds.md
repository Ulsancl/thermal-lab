# 안전한 빌드와 검증 산출물

웹과 Windows 배포 도구는 입력 파일과 상위 폴더의 심볼릭 링크·정션·특수 파일을 거부합니다. 두 빌드 모두 확인한 웹 입력을 새 스테이징 디렉터리에 복사한 후 Vite를 실행합니다. 빌드가 성공하면 완성된 디렉터리를 게시합니다. Windows 패키지는 별도로 확인한 입력을 사용하고, 게시 전 실행 파일의 Electron Fuses와 설치 파일의 체크섬을 확인합니다.

브라우저·데스크톱 테스트도 새 임시 디렉터리에 기록한 다음 종료 시 기존 output 경로로 결과를 게시합니다. 기존 결과 경로에 연결 파일이 있으면 다른 위치에 기록하지 않고 실패합니다. 빌드는 해당 사용자가 소유한 깨끗한 작업 공간에서 실행하세요. POSIX에서는 다른 사용자가 쓸 수 있는 산출물 부모 폴더도 거부합니다. Windows에서는 빌드 계정과 관리자가 작업 폴더를 제어하도록 NTFS ACL을 지정해야 합니다.

개발 서버는 루프백에서만 실행되며 산출물과 스테이징 경로에 대한 파일 요청을 거부합니다. 정적 웹 산출물은 CSP를 포함합니다. 호스팅 설정에서 HTTP 응답 헤더로 `frame-ancestors 'none'`을 함께 적용할 수 있습니다.

이 검증은 다른 사용자가 심어 둔 경로를 따라 비밀 파일을 포함하거나 외부 파일을 덮어쓰는 일을 막기 위한 것입니다. 검증되지 않은 소스 코드나 npm 실행 스크립트 자체를 격리하는 도구는 아닙니다.
