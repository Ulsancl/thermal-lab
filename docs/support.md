# 문제 보고

앱 버전, Windows 버전, GPU·화면 배율·해상도와 함께 재현 순서, 기대 결과, 실제 결과를 [문제 보고](https://github.com/Ulsancl/thermal-lab/issues/new/choose)에 기록하세요. 온도 문제에는 모듈·접촉·팬·전력과 변경 시각이 필요하므로 공유 가능한 작은 실험 파일이 도움이 됩니다. 일시정지 여부와 현재 실험·보관한 비교 중 어느 값인지도 알려 주세요.

손상되거나 새 버전인 파일은 원문 내보내기로 따로 보관하고 덮어쓰지 마세요. 비교 이름·파일 내용·진단 로그의 개인 경로를 확인한 뒤 공유하세요. 문제 보고 기능은 지원 응답 시간·모든 장치 호환성·유료 유지보수 계약을 뜻하지 않습니다.
