# 저장과 복원

프로젝트 형식은 `thermal-lab-project`, 스키마 1, 모형 `thermal-two-node-1`입니다. `experiment`는 최초 설정 `config`, 모형 경과 시간 `elapsedS`, 전력·팬 변경 `events`를 담습니다. `config.ambientC`는 해당 실험의 초기 온도이며 생략하면 25 °C입니다. 불러올 때 초기 온도부터 기록된 조건과 시점 순서대로 재계산합니다.

이벤트는 `{timeS,powerW,fan}`과 선택 항목 `fanSpeedPct`를 담으며 엄격히 증가하는 시간순입니다. `config`와 이벤트 모두 비율을 생략하면 `fan: false`는 0%, `fan: true`는 100%를 뜻합니다. 비율을 명시하면 0–100%의 유한한 수여야 하며 `fan`은 비율이 0보다 큰지 나타냅니다. 0초 이벤트와 유효한 중복 조건 기록도 그대로 보존합니다. 한 실험 안의 모듈·접촉·주변 온도는 고정이며 전력과 팬 비율은 변경할 수 있습니다. 실험 시간은 0–7200초, 이벤트는 최대 256개입니다.

파일에는 비교 이름과 별도 전체 실험 하나, 배속 1/10/60, 온도·흐름·분해·이름표 표시, 선택 부품과 카메라도 담습니다. **재생 중 여부는 저장하지 않으며 불러오기와 재시작은 일시정지 상태입니다.** 온도·그래프 표본·정상값·안내 진행은 저장하지 않고 원래 이력에서 다시 계산합니다. 라이브 생성 API가 무효 이력을 받으면 최초 조건으로 새 실험을 만들 수 있지만, 파일 파서는 이 경로를 사용하지 않고 무효 파일을 거부합니다.

그래프에서 현재·보관 곡선을 따로 표시하는 선택은 잠깐 살펴보기 위한 화면 상태이며 파일 형식을 바꾸지 않습니다. 파일을 열면 두 이력을 함께 보는 상태로 시작합니다. 같은 곡선이 겹쳐도 비교 실험 자체가 사라진 것은 아닙니다.

잘못된 시간순·조건·카메라·알 수 없는 항목이나 버전·1 MiB 또는 JSON 구조 한도 초과 파일은 현재 실험과 원문을 유지한 채 거부합니다. Windows UTF-8 BOM 한 개를 허용합니다. 자동 저장 키는 `thermal-lab-project-v1`입니다. 손상되거나 새 버전인 자동 저장 원문은 덮어쓰지 않고 별도 원문 내보내기를 제공합니다. 브라우저와 설치 앱의 로컬 프로필은 별개이며 외부 파일 백업은 사용자가 보관해야 합니다.

설치 앱의 저장은 같은 폴더에 임시 파일을 쓰고 동기화·닫기를 마친 뒤 이름을 바꿉니다. Windows의 일시적 공유 오류는 총 775 ms 대기를 포함해 최대 6회 교체하며 매번 실제 부모 경로와 일반 파일 여부를 확인합니다. 기존 목적지를 먼저 삭제하지 않고, 실패하면 생성한 임시 파일만 정리합니다. 전원 차단·디스크 고장까지 복구를 보장하지는 않습니다.

같은 앱을 여러 탭에서 열었을 때, 다른 탭이 먼저 바꾼 자동 저장을 감지하면 이 탭은 덮어쓰지 않습니다. 이 탭의 실험도 보관하려면 파일로 저장하고, 최신 자동 저장을 보려면 새로고침하세요.

브라우저 자동 저장은 같은 저장소를 공유하는 탭끼리 Web Locks로 쓰기 순서를 정합니다. 한 번에 한 탭만 기존 기록을 다시 읽고 비교한 뒤 기록합니다. 다른 탭이 그 사이 다른 실험을 저장했다면 이 탭은 덮어쓰지 않습니다. 페이지 위쪽 **이 탭의 실험 내려받기**를 누르면 현재 조건·비교·관찰 시점을 포함한 파일을 받을 수 있습니다. 파일을 받은 뒤 **파일을 저장했어요**를 누르면 해당 시점의 탭 초안이 정리됩니다. 새로고침하면 최신 자동 저장을 엽니다.

Web Locks를 지원하지 않거나 사용할 수 없는 브라우저에서는 기존 기록을 불러올 수 있지만 자동 저장으로 덮어쓰지 않습니다. 같은 버튼이나 **파일 저장**으로 실험을 보관하세요. 숨겨지는 탭은 남은 저장을 요청하지만, 잠금을 기다리는 동안 탭을 닫거나 브라우저를 종료하면 저장할 수 없는 경우가 있습니다. 브라우저가 허용하면 저장이 확인되지 않은 변경과 보관 중인 복구 사본에 대해 닫기 전에 경고합니다. 강제 종료까지 보장하지는 않습니다. 동시 저장 보호는 이 버전의 저장 방식을 사용하는 탭에 적용됩니다. 설치 앱은 동기 자동 저장을 사용하며 브라우저와 같은 프로젝트 형식을 사용합니다.

같은 브라우저 탭을 빠르게 새로고침하면 탭 안에 남긴 임시 기록을 확인합니다. 공유 자동 저장 내용이 그대로면 임시 기록을 복원한 뒤 정상적인 잠금 절차로 다시 저장합니다. 다른 값이 이미 저장됐거나 잠금을 사용할 수 없으면 공유 기록을 먼저 열고, 이전 상태는 위쪽 **이전 실험 복구 사본 내려받기**에서 별도로 받을 수 있습니다. 파일을 받은 뒤 **파일을 저장했어요**를 누를 때까지 복구 사본을 탭에 유지합니다. 저장 권한·공간이 없거나 탭 자체가 닫힌 경우에는 이 임시 복원을 보장하지 않습니다.
