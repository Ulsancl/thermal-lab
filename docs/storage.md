# 저장과 복원

프로젝트 형식은 `thermal-lab-project`, 스키마 1, 모형 `thermal-two-node-1`입니다. `experiment`는 최초 설정 `config`, 모형 경과 시간 `elapsedS`, 전력·팬 변경 `events`를 담습니다. 현재 전력과 최초 전력이 다를 수 있으므로 마지막 조건으로 전체 실험을 다시 가열한 것처럼 해석하지 않습니다. 불러올 때 최초의 25 °C부터 기록된 시점 순서대로 재계산합니다.

이벤트는 `{timeS,powerW,fan}`이며 엄격히 증가하는 시간순입니다. 0초 이벤트와 유효한 중복 조건 기록도 그대로 보존합니다. 한 실험에서 모듈·접촉은 고정하고 전력·팬만 바꿀 수 있습니다. 실험 시간은 0–7200초, 이벤트는 최대 256개입니다. 불러오기에서 수치를 보정하거나 오래된 이벤트를 삭제하지 않습니다.

파일에는 비교 이름과 별도 전체 실험 하나, 배속 1/10/60, 온도·흐름·분해·이름표 표시, 선택 부품과 카메라도 담습니다. **재생 중 여부는 저장하지 않으며 불러오기와 재시작은 일시정지 상태입니다.** 온도·그래프 표본·정상값·안내 진행은 저장하지 않고 원래 이력에서 다시 계산합니다. 라이브 생성 API가 무효 이력을 받으면 최초 조건으로 새 실험을 만들 수 있지만, 파일 파서는 이 경로를 사용하지 않고 무효 파일을 거부합니다.

그래프에서 현재·보관 곡선을 따로 표시하는 선택은 잠깐 살펴보기 위한 화면 상태이며 파일 형식을 바꾸지 않습니다. 파일을 열면 두 이력을 함께 보는 상태로 시작합니다. 같은 곡선이 겹쳐도 비교 실험 자체가 사라진 것은 아닙니다.

잘못된 시간순·조건·카메라·알 수 없는 항목이나 버전·10 MiB 초과 파일은 현재 실험과 원문을 유지한 채 거부합니다. Windows UTF-8 BOM 한 개를 허용합니다. 자동 저장 키는 `thermal-lab-project-v1`입니다. 손상되거나 새 버전인 자동 저장 원문은 덮어쓰지 않고 별도 원문 내보내기를 제공합니다. 브라우저와 설치 앱의 로컬 프로필은 별개이며 외부 파일 백업은 사용자가 보관해야 합니다.

설치 앱의 저장은 같은 폴더에 임시 파일을 쓰고 동기화·닫기를 마친 뒤 이름을 바꿉니다. Windows의 일시적 공유 오류는 총 775 ms 대기를 포함해 최대 6회 교체하며 매번 실제 부모 경로와 일반 파일 여부를 확인합니다. 기존 목적지를 먼저 삭제하지 않고, 실패하면 생성한 임시 파일만 정리합니다. 전원 차단·디스크 고장까지 복구를 보장하지는 않습니다.
